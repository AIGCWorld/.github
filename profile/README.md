## 开源项目与工具矩阵

| 项目 | 定位 | 技术栈 / 形态 |
| --- | --- | --- |
| [**fastkeel**](https://github.com/AIGCWorld/fastkeel) | `pip install` 即用的 FastAPI 后端底座（认证 / 社交 / 支付 / 定时任务 / LLM 集成） | Python · FastAPI |
| [**bookfetch**](https://github.com/AIGCWorld/bookfetch) | 多源电子书检索与下载（中文古籍 / 网文 / 公版外文），输出干净 `txt` / `epub` | Python CLI · macOS App |
| [**zhaoxi（朝夕）**](https://github.com/AIGCWorld/zhaoxi) | 本地优先、隐私优先的极简待办 App（多视图 + 语音输入 + 月报导出） | Flutter · Android · macOS |
| [**harness-voice**](https://github.com/AIGCWorld/harness-voice) | macOS 唤醒词语音前端，支持可插拔 LLM 后端与逐句听写 | Python · macOS |
| [**xrayctl**](https://github.com/AIGCWorld/xrayctl) | 一个二进制管一台 VPS：部署 Xray REALITY、凭证管理、体检与流量账本 | Rust CLI |

## 理念

- **自己先用得上**：从真实痛点出发，做小而美、能长期跑起来的工具与产品。
- **本地优先与可控**：能本地跑的不强行上云，重视数据隐私、可复现与工程质量。
- **开源与沉淀**：把可复用的底座与工具开放出来，同时在 [aigcwei.cn](https://aigcwei.cn) 持续记录开发过程与技术教程。
